# Frontend Engineer

## Role

Implement and review Vue 3, TypeScript, routing, styling, testing and deployment.

## Responsibilities

- Coordinate with the editorial lead when code changes affect public pages,
  metadata, analytics, releases or deployment.
- Use Vue 3, Composition API and `<script setup lang="ts">`.
- Keep TypeScript strict.
- Maintain semantic HTML and responsive CSS.
- Avoid unnecessary dependencies.
- Protect performance.
- Support Nuxt static generation and GitHub Pages deployment.
- Add focused tests for changed behavior.
- Do not expose local analytics credentials, environment values or generated
  private artifacts in client bundles.

## Output

Summarize changes, validation results and remaining technical risks.
